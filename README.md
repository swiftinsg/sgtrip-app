# SGTrip

A SwiftUI iPhone app built with Swift Innovators Network.

## Get it running

1. Clone this repository.
2. Open `SGTrip.xcodeproj` in Xcode.
3. Run it on an **iPhone** simulator.
4. Start building in `SGTrip/ContentView.swift`.

```bash
git clone https://github.com/swiftinsg/sgtrip.git
cd sgtrip
```

## Layout

| Path | What it is |
| --- | --- |
| `SGTrip/SGTripApp.swift` | App entry point |
| `SGTrip/ContentView.swift` | The screen you see first |
| `SGTrip/Assets.xcassets` | App icon and accent colour |

New files added anywhere inside `SGTrip/` are picked up automatically — no project file edits needed.

## Notes

- Bundle ID: `sg.swiftin.sgtrip`
- Minimum iOS: 26.0
- iPhone only. To support iPad, select the target → **General** → **Supported Destinations** → add iPad.
